# ElevenLabs v4: текст и голос

Опыт «Бородино», «У лукоморья» и Блока.

## Подготовка текста

- **Аудиотеги v4** пишутся в квадратных скобках **по-английски**, так модель понимает их лучше. Тег действует до следующего тега. Ставь их по смыслу и не чаще одного на 1–2 строки: `[calm, warm narrator]`, `[old soldier, gravelly voice, slowly, with quiet pride]`, `[whispering]`, `[sighs]`, `[excited]`, `[sadly]`, `[firmly]`, `[shouting]`, `[choked up, quietly]`.
- **Паузы.** SSML `<break>` в v4 не работает. Между строками ставь `[short pause]`, между строфами `[long pause]`. Переносы строк сохраняй: модель делает на них короткую паузу.
- **Буква «ё» везде.** Без неё TTS читает «е».
- **Ударения** ставь комбинируемым акутом U+0301 (`знамена́`), но **только там, где TTS почти наверняка ошибётся**: архаизмы, редкие слова, поэтические ударения ради размера, омографы (за́мок/замо́к), имена и названия. Если не уверен, лучше не ставь. Иногда v4 на них спотыкается; отдельный файл без ударений не нужен, утилита снимает их сама (`--stress strip`).
- **Числа и сокращения** пиши словами: «тысяча восемьсот двенадцатый», «Михаил Юрьевич».
- **Кавычки** у прямой речи можно оставить, но под реплику ставь свой тег (`[young man, curious]`). Внешние кавычки монолога на весь стих убирай.
- **Заглавие** не озвучиваем: название и автор показываются на заставке.
- **Один файл.** Весь текст лежит в `elevenlabs.txt`. Утилита сама режет его по строфам, если он длиннее лимита v4 (10 000 символов в запросе), и склеивает куски. На длинном тексте v4 постепенно уходит в другую интонацию; кривую строфу можно перегенерировать отдельно: `node run.js generate --text <файл> --voice-id <ID> --out <файл>`.

## Настройки (в `voice.json`)

- Модель: **Eleven v4**, не Turbo и не Flash. Здесь эмоция важнее скорости. Это значение утилиты по умолчанию.
- Язык: `ru`, тоже по умолчанию.
- `stability`: для стиха начинай с 0.5 (Natural). Ниже даёт больше эмоций, но и больше ошибок, выше звучит ровно и монотонно.
- `similarity_boost`: 0.75–1.0.
- Speed в v4 нет: стих читают медленнее прозы, поэтому темп задавай тегом `[slowly]`.
- Дубли: каждый запуск утилиты тратит символы, поэтому новый дубль делай только по просьбе пользователя (`--overwrite`). Отдельно скажи, на какие строфы обратить внимание: кульминация, прямая речь, финал.

ElevenLabs пишет настройки в имя файла: `..._pvc_sp97_s30_sb76_v4.mp3`. Здесь `pvc` означает голос из библиотеки (Professional Voice Clone), `sp` скорость в процентах, `s` stability, `sb` similarity boost, `v4` модель. По имени присланного файла запиши фактические настройки в `voice.json`.

## Каталог голосов

Каталог лежит в `possible-voices.md` в корне проекта, рядом с `possible-styles.md`.

Утилите нужен настоящий ID. Голос без ID ищи по имени: `node run.js voices --search "<имя>"`, а если его нет в списке аккаунта — в Voice Library на сайте (фильтр Language: Russian). Не выдумывай ID: если не проверил, пиши «найти по имени». Непроверенный ID тоже проверь через `voices --search`, прежде чем предлагать голос.

Голоса из Voice Library через API недоступны на бесплатном тарифе, у некоторых есть множитель цены: фактическую стоимость показывает `actualCostUsd` в `RESULT_JSON`.

Женский голос в каталоге пока один (Marina). Для стихов от женского лица (Цветаева, Ахматова) или детских можно поискать другие в Voice Library.

## Озвучка по ролям

Если в тексте есть прямая речь нескольких лиц и пользователь согласен на несколько голосов, в `elevenlabs.txt` ставь метки `#роль` отдельной строкой, а в `voice.json` добавляй `cast`. Пример — `texts/Другое/Илья Муромец и Соловей-разбойник/voice/`: `build.py` режет текст на куски, генерирует их по одному, выравнивает громкость и склеивает `voice.mp3`, `timings.py` считает `timings.json`. Плюс: кривую реплику можно перегенерировать отдельно. Цена та же, что у одного голоса.

## Шаблон `voice.json`

```json
{
  "voice_id": "<ID>",
  "name": "<Имя>",
  "settings": {
    "stability": 0.5,
    "similarity_boost": 0.75
  }
}
```

Голос сверху `elevenlabs.txt` утилита ищет в строке `Голос: <Имя> (ID: <voice_id>)`. Если в папке есть `voice.json`, он важнее этой строки.
