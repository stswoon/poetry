# generate-elevenlabs-voice — инструкция для агентов

Утилита делает голос для стиха через ElevenLabs API (Eleven v4).
Полное описание — [README.md](README.md). Здесь только то, что нужно агенту.

## Команды

```powershell
cd D:\mycode\poetry\utils\generate-elevenlabs-voice
node run.js key                           # проверить ключ и остаток
node run.js voices --language ru          # найти голос
node run.js generate --poem "Пушкин/Зимний вечер" --dry-run
node run.js generate --poem "Пушкин/Зимний вечер"
```

Результат по умолчанию — `texts/<Поэт>/<Стих>/voice.mp3`.
`--dry-run` не требует ключа и не тратит символы.

## Как понять результат

- Последняя строка stdout: `RESULT_JSON: {...}`.
- `ok: true` — готово; `output` — путь к аудио.
- `ok: false` — ошибка; код выхода `1`.
- Код `2` — неверные аргументы.

## Правила

- Сначала `--dry-run`, потом реальная генерация.
- Ключ — только `ELEVENLABS_API_KEY` в корневом `.env` или в окружении; вписывает его
  пользователь. Не печатать ключ, не просить его в чат, не подставлять в команды:
  флагов `--key` и `key --set` нет.
- Флаги-переключатели не забирают следующее слово; значение — только через `=`.
- Не перезаписывать `voice.mp3` без явного согласия пользователя (`--overwrite`).
- Eleven v4 не поддерживает `speed` и `style`; темп — тегами `[slowly]`, `[rushed]`.
- Eleven v4 не поддерживает SSML; паузы — `[short pause]`, `[pause]`, `[long pause]`.
- Один запрос v4 — до 10 000 символов; утилита режет и склеивает сама.
- Для склейки нескольких кусков нужен `ffmpeg`.
