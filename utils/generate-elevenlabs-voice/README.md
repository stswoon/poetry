# generate-elevenlabs-voice

Голос для стиха через ElevenLabs API и модель **Eleven v4** (`eleven_v4`).

Утилита читает `texts/<Поэт>/<Стих>/elevenlabs.txt`, берёт только часть после
разделителя «ТЕКСТ ДЛЯ ОЗВУЧКИ», отправляет её в ElevenLabs и кладёт готовый
`voice.mp3` рядом — туда, откуда его берёт HyperFrames.

Без npm-зависимостей: только Node.js 20+ и `fetch`. `ffmpeg` нужен, если стих
длиннее лимита модели и его приходится генерировать кусками.

---

## Быстрый старт

```powershell
cd D:\mycode\poetry\utils\generate-elevenlabs-voice

# 1. Один раз вписать ELEVENLABS_API_KEY=<ключ> в корневой .env (образец — .env.example)
#    и проверить его
node run.js key

# 2. Посмотреть, что и за сколько будет озвучено
node run.js generate --poem "Пушкин/Зимний вечер" --dry-run

# 3. Сгенерировать голос
node run.js generate --poem "Пушкин/Зимний вечер"
```

Результат: `texts/Пушкин/Зимний вечер/voice.mp3`.

Ключ создаётся в кабинете ElevenLabs: <https://elevenlabs.io/app/developers/api-keys>.
Он хранится в корневом `.env` проекта (ключ `ELEVENLABS_API_KEY`) и в git не попадает.
Вместо файла можно задать `ELEVENLABS_API_KEY` (или `XI_API_KEY`) в окружении — переменная
окружения важнее `.env`. Через аргументы командной строки ключ не передаётся: так он не
попадает в историю оболочки и в чат. Для EU/US-residency базовый адрес
можно переопределить через `ELEVENLABS_API_BASE` (по умолчанию
`https://api.elevenlabs.io`).

`--dry-run` не требует ключа и не тратит символы: он показывает голос, настройки,
куски и примерную цену.

## Что важно знать про Eleven v4

- В v4 доступны только **Stability** и **Similarity** (`stability`,
  `similarity_boost`). Слайдеров **Speed** и **Style** нет; API их не принимает.
  Темп задаётся аудио-тегами: `[slowly]`, `[rushed]`, `[whispers]` и т. п.
- **SSML не поддерживается.** `<break time="1.5s" />` не сработает. Паузы — теги
  `[short pause]`, `[pause]`, `[long pause]`.
- Один запрос — до **10 000 символов** (~10 минут аудио). Утилита сама режет
  длинный текст по строфам/строкам и склеивает куски.
- v4 поддерживает 90+ языков, включая русский. Язык передаётся как `ru`.
- Модель недетерминирована: два запуска могут звучать немного по-разному.
- Цена v4 — около **$0.08 за 1 000 символов** (v4 Turbo — около $0.04).
  Это ориентир из `config.json`; точную стоимость ElevenLabs показывает в
  заголовке `character-cost`, утилита его читает.

Если хочется другую модель, есть `--model v3`, `--model v2`, `--model flash`.
Для них утилита сама переведёт теги пауз в SSML `<break>`.

## Как читается `elevenlabs.txt`

Файл делится на две части строкой вида:

```
=========== ТЕКСТ ДЛЯ ОЗВУЧКИ — копировать отсюда ===========
```

- Всё **до** разделителя — блок «Голос»: он не озвучивается.
- Всё **после** — текст для озвучки.
- Название и автор в текст не входят: они показываются на заставке.
- Если разделителя нет и файл начинается с блока «ГОЛОС», утилита остановится
  и попросит добавить разделитель.
- Если разделителя нет и это обычный текстовый файл, он будет озвучен целиком.

**Голос.** ID можно не указывать в команде: утилита ищет его в блоке «Голос»
по шаблону `Голос: Имя (ID: xxxxx)` (как в существующем «Зимнем вечере»).
Приоритет: `--voice-id` → `voice.json` → блок «Голос» → ошибка.

**Ударения.** Знак U+0301 (`за́мок`) по умолчанию сохраняется. ElevenLabs не
документирует его поддержку; если в голосе слышны артефакты, запусти с
`--stress strip` — утилита снимет все знаки ударения.

**Паузы.** `[short pause]` / `[pause]` / `[long pause]` остаются как есть для
v3/v4. Для старых моделей они автоматически становятся
`<break time="0.4s|0.8s|1.5s" />`. Обратное тоже работает: `<break>` для v3/v4
становится аудио-тегом.

## `voice.json` — голос и настройки для конкретного стиха

Необязательный файл рядом с `elevenlabs.txt`. Удобно, когда голос и настройки
надо зафиксировать, а не держать в блоке «Голос».

```json
{
  "voice_id": "vQxSi2EuaRWwBw3nn6dK",
  "name": "Marat — Warm, Calm",
  "model_id": "eleven_v4",
  "language_code": "ru",
  "output_format": "mp3_44100_128",
  "settings": {
    "stability": 0.5,
    "similarity_boost": 0.75
  }
}
```

Все поля необязательны. Настройки можно писать и на верхнем уровне:

```json
{ "voice_id": "vQxSi2EuaRWwBw3nn6dK", "stability": "natural", "speed": 0.9 }
```

Приоритет: **CLI → `voice.json` → `config.json`**.
`stability` понимает `creative` (0), `natural` (0.5), `robust` (1).
`style` и `speed` для v4 будут пропущены с предупреждением.

## Команды

### `key`

```powershell
node run.js key                         # проверить ключ и остаток символов
```

Показывает тариф, использованные/оставшиеся символы и дату сброса. Сам ключ
никогда не печатается целиком. Сохранить или сменить ключ — правкой корневого `.env`.

### `voices`

Поиск голоса в библиотеке ElevenLabs:

```powershell
node run.js voices --language ru
node run.js voices --language ru --search "male"
node run.js voices --language en,ru --limit 50
node run.js voices --language ru --json
```

В таблице — ID, имя, тип, язык, пол, возраст и описание. ID можно вставить в
`voice.json` или передать через `--voice-id`. Несколько языков уходят в API повтором
параметра (`?language=en&language=ru`).

### `generate`

```powershell
node run.js generate --poem "Пушкин/Зимний вечер"
node run.js generate --poem "texts/Пушкин/Зимний вечер" --dry-run
node run.js generate --text "D:\poem.txt" --voice-id <ID> --out "D:\voice.mp3"
```

`--poem` принимает папку стиха, путь к `elevenlabs.txt` или короткий путь
`Поэт/Стих` (ищется в `texts/`). Позиционный аргумент тоже работает:

```powershell
node run.js generate "Пушкин/Зимний вечер"
```

| Опция | Что делает |
|---|---|
| `--poem <путь>` | Папка стиха с `elevenlabs.txt` или сам файл |
| `--text <файл>` | Явный файл с текстом (альтернатива `--poem`) |
| `--out <файл>` | Куда писать аудио; по умолчанию `<папка стиха>/voice.mp3` |
| `--voice-id <ID>` | ID голоса; иначе `voice.json` или блок «Голос» |
| `--model <id>` | `eleven_v4` (по умолчанию), `v4-turbo`, `v3`, `v2`, `flash` |
| `--language <код>` | Язык, по умолчанию `ru`; `none` — не передавать |
| `--format <формат>` | `mp3_44100_128` (по умолчанию), `wav_44100`, `opus_48000_128`, `pcm_44100`… |
| `--stability <0..1>` | Stability; можно `creative` / `natural` / `robust` |
| `--similarity <0..1>` | Similarity |
| `--style <0..1>` | Только для моделей со style; для v4 — ошибка |
| `--speed <0.7..1.2>` | Только для моделей со speed; для v4 — ошибка |
| `--speaker-boost` | Включить speaker boost |
| `--no-speaker-boost` | Выключить speaker boost |
| `--stress keep\|strip` | Оставить или снять знаки ударения U+0301 |
| `--max-chars <N>` | Максимум символов в одном запросе |
| `--overwrite` | Перезаписать существующий файл |
| `--dry-run` | Показать план и цену, не обращаясь к API |
| `--no-check` | Не проверять остаток символов перед генерацией |
| `--debug` | Печать стека ошибки |

Флаги-переключатели (`--dry-run`, `--overwrite`, `--no-check`, `--speaker-boost`,
`--no-speaker-boost`, `--json`, `--debug`) не забирают следующее слово:
`--dry-run "Пушкин/Зимний вечер"` — это dry-run для этого стиха. Значение им даётся
только через `=` (`--dry-run=false`), а непонятное значение — ошибка, а не тихий «нет».

Если файл уже существует, без `--overwrite` утилита остановится — случайно
потратить символы на повторную генерацию нельзя.

## Длинный текст и склейка

Лимит берётся из `config.json` (`modelLimits`) с запасом 500 символов. Текст
режется сначала по строфам, потом по строкам, предложениям и словам — так,
чтобы кусок не превысил лимит.

Для нескольких кусков:

- куски генерируются последовательно;
- в следующий запрос передаются `previous_request_ids` (до 3) для ровного
  голоса на стыках; для `eleven_v3` этот параметр не работает и не передаётся;
- если API не вернул `request-id`, используется `previous_text`/`next_text`;
- MP3/WAV/OGG склеиваются через `ffmpeg -f concat -c copy` без перекодирования;
- `pcm_*`, `ulaw_*`, `alaw_*` склеиваются как байты.

Склейка идёт во временной папке, а не в папке стиха, поэтому кириллица в пути
стиха не мешает ffmpeg.

## Цена и результат

Перед запуском утилита показывает оценку:

```
Оценка:     ~$0.101 (1 260 симв. × $0.08 / 1000)
```

После генерации — фактическое значение из заголовка `character-cost`, если
ElevenLabs его вернул.

Последняя строка stdout — машиночитаемый итог:

```
RESULT_JSON: {"ok":true,"dryRun":false,"output":"...voice.mp3","bytes":2438,"durationSec":73.6,"voiceId":"...","modelId":"eleven_v4","chunks":1,"characters":1260,"actualCharacters":1260,"estimatedCostUsd":0.1008,...}
```

При ошибке:

```
RESULT_JSON: {"ok":false,"error":"..."}
```

Коды выхода: `0` — успех, `1` — ошибка выполнения/API, `2` — неверные аргументы.

---

## Ошибки

| Симптом | Что делать |
|---|---|
| `401` | Проверить ключ: `node run.js key`; заменить `ELEVENLABS_API_KEY` в корневом `.env` |
| `402` | Закончились кредиты/средства на ElevenLabs |
| `403` | Тариф не позволяет голос/формат (например, 192 kbps — Creator+) |
| `404` | Неверный `voice_id`; найти голос: `node run.js voices --language ru` |
| `422` | Неверные параметры; для v4 убери `--speed`/`--style` |
| `429` | Лимит запросов; утилита сама повторяет с паузой |
| `5xx` | Ошибка ElevenLabs; утилита повторяет, потом просит повторить позже |
| `FFmpeg не найден` | Установить ffmpeg или генерировать одним куском |
| `Кракозябры` в консоли | `chcp 65001` или Windows Terminal |

## Файлы

```
generate-elevenlabs-voice/
  run.js              # CLI: key | voices | generate
  config.json         # модель, лимиты, цены, настройки по умолчанию
  voice.example.json  # пример voice.json для папки стиха
  lib/
    config.js         # пути проекта и config.json
    key.js            # ключ из env / корневого .env
    elevenlabs.js     # API: subscription, voices, text-to-speech
    text.js           # разбор elevenlabs.txt, ударения, теги, нарезка
    audio.js          # ffmpeg concat и ffprobe
    format.js         # время, цена, дата
```

Аргументы, чтение `.env`, HTTP с повторами и форматирование байтов — общие для всех
хелперов, лежат в `utils/lib/` (см. [utils/README.md](../README.md)).

`config.json` можно править: модель по умолчанию, язык, формат, лимиты, цены,
настройки голоса, число повторов и таймауты.

## Для агентов

- Сначала `--dry-run`, потом реальная генерация.
- Не печатать ключ и не подставлять его в команды; использовать корневой `.env` или
  `ELEVENLABS_API_KEY`.
- Читать итог из `RESULT_JSON`; `ok:false` — ошибка, код выхода `1`.
- Для v4 не передавать `speed`/`style`; темп — аудио-тегами.
- Не перезаписывать `voice.mp3` без явного согласия пользователя.
- Если стих длинный, проверять, что `ffmpeg` доступен.
