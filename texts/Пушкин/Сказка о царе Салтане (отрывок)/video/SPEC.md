# Морской приключенческий комикс

Пушкин, «Сказка о царе Салтане», 26 строк от «Ветер на море гуляет…». Выбор пользователя: энергичный морской приключенческий комикс, Ivan Nazarov. Сценарий: ../script.md.

- 1920×1080, 30 fps; 4 с вступления + 48.64 с голоса + 6 с финала = 58.64 с (кодирование с точностью одного кадра).
- Одна история: корабль → открытие острова → порт → приглашение Гвидона → разговор → товары и карта → отплытие.
- Основные цвета: тёмный контур #12263A, светлая бумага #FFF5DD, бирюзовое море, коралловые акценты. Толщина основных рисованных контуров 4–8 px.
- Иллюстрация сверху до y=760; подписи внутри x=192…1728, y=789…948. Две строки по58px, неподвижный текст, прозрачный по смыслу монтаж.
- Впереди крупный узнаваемый парусник; моряки с разными лицами, Гвидон с выразительным жестом. В портовой сцене купола, арка, пушка, причал. Иллюстрации кодом, без заимствования дизайна экранизаций.
- Девять самостоятельных sub-compositions плюс одна общая композиция титров строк. Каждая сцена имеет свой SVG и paused GSAP timeline; кривые входа позиций — Framer Motion spring, stiffness150, damping18, mass1.
- Перекрытие соседних сцен0.34с; направленное раскрытие0.32с. Смена крупности0.55–0.75с. Парус и вода движутся разными периодами, движения рук сдвинуты по времени.
- Тайминги голоса берутся только из ../timings.json. Строки и пунктуация сверяются с ../poem.md при каждой сборке. Генератор проверяет уникальность id.
- Локальные Windows Segoe UI Semibold и Georgia Bold скопированы в assets/fonts для предсказуемого рендера; программы и шрифты не устанавливаются.
- Оригинальная музыка112 BPM и редкие синтезированные шумы, музыка под голосом на19дБ ниже. Мастер−14 LUFS ±1, true peak не выше−1dBTP.

## Не использовать

Статичные слайды вместо действия, одинаковое движение всех героев, прыгающие буквы, тряску титров, строб, полноэкранные вспышки, речевые пузыри вместо полного текста, мелкие подписи, перекрытие текста рисунком, череду карточек интерфейса, изображения из мультфильмов, внешние шрифтовые и JS CDN.

## Проверки

HyperFrames check и обзор кадров до рендера; короткая рендер-проба; полная версия только после музыки. Затем ffprobe, измерение громкости, проверка каждого текста и независимая проверка готового MP4. На слух голос и музыку проверяет пользователь.
